# Crownfield_Hospital_Database
CPU4:103 Database Development _ Crownfield Hospital Management System
## Project Overview
This project is a Crownfield Hospital Management System developed using MySQL Workbench for the CPU4:103 Database Development assessment.

The database contains 11 related tables for managing patients, clinicians, appointments, diagnoses, medicines, prescriptions and follow-up records.

## Software Requirements
- MySQL Server
- MySQL Workbench

## Database Setup
1. Open MySQL Workbench and connect to MySQL Server.
2. Run `database creation.sql` to create the database.
3. Run the table creation SQL scripts to create the tables.
4. Run the Part B SQL scripts to insert sample records.
5. Run the Part C SQL scripts to test database queries.
6. Run the Part D SQL scripts to demonstrate security controls and testing.
